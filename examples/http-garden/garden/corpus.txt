# Request-smuggling and parser-confusion patterns, one payload per line, escaped like a JSON string
# (\r, \n, \t, \", \\, \u00XX). The Lean cases in HttpReaderSpecCases.scala are added to these.
# Content-Length and Transfer-Encoding together (CL.TE / TE.CL)

POST / HTTP/1.1\r\nHost: a\r\nContent-Length: 0x3\r\n\r\nabc

POST / HTTP/1.1\r\nHost: a\r\nContent-Length: 99999999999999999999\r\n\r\nabc
