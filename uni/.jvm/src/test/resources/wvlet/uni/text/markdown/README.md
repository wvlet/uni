# Markdown spec examples

- `commonmark-spec-0.31.2.json`: the examples of the [CommonMark Spec 0.31.2](https://spec.commonmark.org/0.31.2/) (https://spec.commonmark.org/0.31.2/spec.json), by John MacFarlane, licensed under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/).
- `gfm-extensions.json`: the extension examples (tables, task lists, strikethrough, autolinks, tag filter) of the [GitHub Flavored Markdown Spec 0.29-gfm](https://github.github.com/gfm/), extracted from https://github.com/github/cmark-gfm/blob/master/test/spec.txt and licensed under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). `→` in the spec is converted to a tab.

`MarkdownSpecTest` runs these examples against `wvlet.uni.text.markdown.Markdown`.
