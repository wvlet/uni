# Enum cases in Surface for runtime Weaver codecs

## Context

`derives Weaver` encodes an enum with any parameterized case in the sealed-trait format: an `"@type"` discriminator next to flat fields, with singletons as `{"@type":"Zero"}` (see [`2026-11-06-weaver-recursive-sum-types.md`](2026-11-06-weaver-recursive-sum-types.md)). RPC/HTTP code and MCP tool schemas resolve codecs at runtime with `Weaver.fromSurface`. `EnumSurface` carried only a name → singleton lookup, so the runtime path wrote these enums as plain strings and dropped parameterized cases' fields. Data written by one path could not be read by the other.

## Decision

- `EnumSurface` has a `cases: Seq[EnumCase]` field. Each entry is `EnumCase.Singleton(name, value)` or `EnumCase.Parameterized(name, surface)`, in declaration order.
- The Surface macro fills `cases` only for non-generic enums with a parameterized case. Empty `cases` means a string enum, so string enums generate no extra code and keep their encoding.
- Case names are the case symbol names, which equal the `productPrefix` the derived codec writes.
- `fromSurface` builds the same `SealedTraitWeaver` as the derived codec. It uses `fromSurface` for each case's Surface and `SingletonWeaver` for singletons, so recursion goes through `LazyWeaver`.
- `SealedTraitWeaver` also reads a bare string that names a singleton case (`"Zero"`), the form the runtime path wrote before, so stored data and older clients still decode. It still writes only the object form.
- MCP `JsonSchema` describes these enums as `oneOf` with one object per case: the discriminator as a `const`, plus the case fields. It resolves `LazySurface` references so a recursive enum is recognized.
- The 2-argument `EnumSurface` constructor and `apply` stay, so code generated by earlier Surface macros still links.

## Alternatives

- A separate `EnumAdtSurface` subclass: code that matches `EnumSurface` would miss these enums and fall back to the lossy empty-object codec.
- Recording cases for every enum: more generated code for each string enum, with no runtime use.
- Runtime reflection over enum cases: not available on Scala.js or Scala Native.

## Consequences

- Generic enums (`enum Maybe[+A]`) still get no `EnumSurface`, because `Surface.of[Maybe[Int]]` takes the applied-type path, and the macro leaves `cases` empty for them in any case.
- `JsonSchema` names the discriminator from the default `WeaverConfig` (`"@type"`). A server that changes `discriminatorFieldName` would publish a schema that does not match its encoding.
  - Not a mismatch today: MCP, RPC, and HTTP servers all encode with the default `WeaverConfig`. `JsonSchema.Options.discriminatorFieldName` (default `"@type"`) is ready for a server that later accepts a WeaverConfig to pass its name.
