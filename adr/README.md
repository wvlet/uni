- [`2026-07-06-curl-shim-weak-linking.md`](2026-07-06-curl-shim-weak-linking.md) — `uni_curl_shim.c` resolves libcurl's variadic setopt/getinfo from the process's already-loaded modules (`dlsym(RTLD_DEFAULT, ...)` on POSIX, `GetProcAddress` over `EnumProcessModules` on Windows) inside a run-once init, not C-level `extern`s, so downstream Scala Native builds that don't use `CurlBindings` still link (issue #622). Read before touching the shim: covers why `__attribute__((weak))` on the extern fails on macOS, why `RTLD_DEFAULT` (not `dlopen`) is the right lookup, why MSVC needs the whole `#if defined(_WIN32)` half (no `<dlfcn.h>`/`<pthread.h>`) and `PSAPI_VERSION 2`, why libcurl must now be linked dynamically, why the variadic-typedef ABI trick from #580 is still load-bearing, why `_GNU_SOURCE` is required on glibc, why lazy init needs a run-once guard not just "same value written twice", and why guarding this takes both the Windows Scala Native job and a separate `nm` check (the build's unconditional `-lcurl` blinds every native job to the #622 regression).

- [`2026-07-08-native-socket-shim.md`](2026-07-08-native-socket-shim.md) — `uni_socket_shim.c` holds the three socket calls that differ on Windows (`WSAStartup`, `WSAPoll` for `poll`, `closesocket` for `close`), so uni's Native HTTP server links and runs there. Read before touching `NativeSocket` or adding Windows CI: covers why the OS split cannot live in Scala (no per-OS source dir, and DCE keeps reachable branches, so *referencing* `posix.poll` breaks the link), why the whole readable-wait verdict is in C (`struct pollfd.fd` is an `int`, `WSAPOLLFD.fd` is a 64-bit `SOCKET`), why `#pragma comment(lib, "ws2_32.lib")` rather than `@link("ws2_32")` (the #622 trap), and that `close()` on a Windows socket links but leaks it.

- [`2026-10-14-http-server-secure-defaults.md`](2026-10-14-http-server-secure-defaults.md) — HTTP servers are secure by default: loopback bind, generic 500/RPC error bodies (`withDetailedErrors` to opt in; MCP keeps details), WebSocket `Origin` check before the route filter (`withAllowedOrigins`), CR/LF header rejection at both builder and writer, Netty `RequestReadTimeoutHandler`, a Node.js body limit, bounded Netty request decompression, a `Host` allowlist against DNS rebinding, SSE/WebSocket connection caps, RPC endpoint filtering (`@rpcIgnore`, library mixins), `RouterHandler` exceptions propagated to filters, and Electron IPC sender checks. - [`2026-10-14-rx-completion-semantics.md`](2026-10-14-rx-completion-semantics.md) — `OnCompletion` is terminal: `filter` no longer completes on rejection, `Rx.const` completes after its value, `flatMap` waits for its nested stream (and treats a nested error as its end), and `runOnce` delivers only the first event. Read before touching `RxRunner` operators or any `runOnce`/`await` consumer; covers why `Rx.future`-based async tests used to pass vacuously and why Node async handlers got 404.
- [`2026-10-19-rx-take-completion.md`](2026-10-19-rx-take-completion.md) — `take(n)` completes right after the nth value, cancels its upstream and drops late events; `take(n <= 0)` completes without subscribing; `RxVar` propagates over a subscriber snapshot so cancelling during an update is safe. Read before touching `TakeOp`, `RxVar.propagateEvent`, or code that awaits the first matching value.

- [`2026-10-22-weaver-omit-none-fields.md`](2026-10-22-weaver-omit-none-fields.md) — `WeaverConfig.omitNoneFields` (opt-in, default `false`) drops None-valued Option fields of case classes when packing, with a map header that counts only written fields, matching Airframe's wire shape. - [`2026-10-22-rpc-error-stack-trace.md`](2026-10-22-rpc-error-stack-trace.md) — RPC error bodies carry a `stackTrace` array in Airframe's shape when `RPCException.shouldReportStackTrace` is true (every status but U13/U14, unless `noStackTrace`). - [`2026-10-22-scoped-router-filters.md`](2026-10-22-scoped-router-filters.md) — `Router` filters are scoped per route (`Route.filterSurfaces`, outermost first) instead of one `filterSurfaceOpt` per router, so composing routers keeps each subtree's filters.
